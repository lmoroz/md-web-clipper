# MD Web Clipper

Браузерное расширение: сохраняет содержательную часть веб-страницы как
Markdown-файл (вместе с картинками) или копирует markdown в буфер обмена.
Извлечением занимается движок [Defuddle](https://github.com/kepano/defuddle).

Особенности:

1. Чистый markdown без frontmatter/properties.
2. Кнопки: **Save to «папка»** (в ранее выбранную папку), **Save to another folder** и **Copy to clipboard**.
3. Картинки сохраняются в подпапку `«Имя_файла»_files/` рядом с md-файлом,
   ссылки в md — относительные (галочка в попапе, можно отключить).
4. Заголовки вида `### 4\. Header` не экранируются → `### 4. Header`.
5. Подчёркивания не экранируются: `story_book`, а не `story\_book`.
6. Title страницы всегда ставится первым H1 (`# Заголовок`) документа.
7. Корректно обрабатывает Яндекс Вики и Яндекс Трекер: сложные таблицы,
   внутренние якорные ссылки, авторы и даты комментариев, закрытые
   картинки-аттачи.

## Установка в Chrome / Edge / Brave

1. Скачать `md-web-clipper-chrome-vX.Y.Z.zip` со страницы
   [Releases](../../releases) и распаковать в постоянную папку
   (браузер будет читать расширение из неё — не удалять и не перемещать).
2. Открыть `chrome://extensions` (в Edge — `edge://extensions`).
3. Включить **«Режим разработчика»** (переключатель в правом верхнем углу).
4. Нажать **«Загрузить распакованное расширение»** и выбрать распакованную
   папку.

Обновление: скачать новый zip, распаковать в ту же папку поверх старой,
на `chrome://extensions` нажать ⟳ на карточке расширения.

## Установка в Firefox

Firefox не даёт установить неподписанное расширение насовсем, поэтому два
варианта:

**Временно (обычный Firefox):** `about:debugging#/runtime/this-firefox` →
**«Загрузить временное дополнение…»** → выбрать
`md-web-clipper-firefox-vX.Y.Z.zip` (распаковывать не нужно). Расширение
живёт до перезапуска браузера.

**Постоянно (Firefox Developer Edition, Nightly или ESR):**

1. В `about:config` поставить `xpinstall.signatures.required` = `false`.
2. Переименовать zip в `.xpi` и открыть его в Firefox (`about:addons` →
   шестерёнка → «Установить дополнение из файла…»).

Примечание: в Firefox нет File System Access API, поэтому файлы уходят в
папку «Загрузки» (`Имя.md` + `Имя_files/`), без выбора папки.

## Использование

Открыть страницу → кликнуть иконку расширения. В попапе: имя файла
(редактируемое), предпросмотр markdown (тоже редактируемый), галочка
«Скачивать картинки» и кнопки сохранения.
Save to another folder (при первом запуске — Save to folder…) открывает маленькое окно, которое просит выбрать папку на диске и пишет туда `Имя.md` + `Имя_files/img-01.png…` одним действием, без «Загрузок».
Папка запоминается, и в попапе появляется большая кнопка **Save to «папка»**: она сохраняет сразу в эту папку (после перезапуска браузера нужен один клик «Выбрать папку и сохранить», потому что разрешение Chrome сбрасывает).
Сменить папку — кнопка Save to another folder.

Видео и аудио со страницы остаются на своём месте как HTML-теги `<video src>` / `<audio src>`.
Если на странице они есть, в попапе появляется галочка «Скачивать видео» с числом файлов и суммарным размером, состояние галочки запоминается.
При сохранении файлы потоково пишутся в `Имя_files/vid-01.mp4…`, без загрузки в память, а окно сохранения показывает прогресс в мегабайтах.
Ссылка в markdown становится относительной только для реально сохранённого файла, иначе остаётся исходный URL.
HLS/DASH-потоки (`.m3u8`, `blob:`) сохранить нельзя, они остаются ссылками.
Видео рендерится там, где просмотрщик понимает HTML `<video>` (VS Code, Typora и т.п.).

Copy to clipboard копирует markdown с исходными (абсолютными) ссылками
на картинки и видео.

Там, где выбор папки недоступен (Firefox, Brave со строгими настройками),
файлы автоматически скачиваются в «Загрузки».

## Сборка из исходников

```bash
npm install
npm run build      # esbuild → dist/ (Chrome) и dist-firefox/ (Firefox)
npm run package    # + release/md-web-clipper-{chrome,firefox}-vX.Y.Z.zip
```

Версия берётся из `package.json` и при сборке подставляется в манифесты
обоих вариантов. Firefox-сборка отличается только блоком
`browser_specific_settings.gecko` в манифесте.

Исходники: `src/content.js` (извлечение + конвертация, инжектится в
страницу), `src/popup.js` (кнопки, скачивание картинок),
`src/save.js` (окно записи файлов, потоковое скачивание видео), `src/links.js` (переписывание ссылок), `src/manifest.json` (MV3).

Технические детали: `defuddle/full` — предсобранный бандл со встроенным
Turndown, поэтому лишнее экранирование убирается пост-обработкой markdown
(функция `fixEscaping` в `content.js`), код-блоки при этом не затрагиваются.
