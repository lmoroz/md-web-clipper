# MD Web Clipper

Минимальный клон Obsidian Web Clipper: сохраняет содержательную часть страницы
как Markdown-файл. Работает на том же движке извлечения (Defuddle), что и
оригинальное расширение, но без всего, что связано с Obsidian.

Что отличается от оригинала:

1. Нет properties-шапки (frontmatter) — только чистый markdown.
2. Вместо «Add to Obsidian» две кнопки: **Save file** и **Copy to clipboard**.
3. Картинки сохраняются в подпапку `«Имя_файла»_files/` рядом с md-файлом,
   ссылки в md — относительные (галочка в попапе, можно отключить).
4. Заголовки вида `### 4\. Header` больше не экранируются → `### 4. Header`.
5. Подчёркивания не экранируются: `story_book`, а не `story\_book`.
6. Title страницы всегда ставится первым H1 (`# Заголовок`) документа.

## Установка в Chrome

1. `chrome://extensions` → включить «Режим разработчика».
2. «Загрузить распакованное расширение» → выбрать папку `dist`.

## Использование

Открыть страницу → кликнуть иконку расширения. В попапе: имя файла
(редактируемое), предпросмотр markdown (тоже редактируемый), галочка
«Скачивать картинки» и две кнопки. Save file открывает маленькое окно,
которое один раз просит выбрать папку на диске — и пишет туда
`Имя.md` + `Имя_files/img-01.png…` одним действием, без «Загрузок».
Папка запоминается: следующие сохранения проходят сами (после перезапуска
браузера — один клик «Выбрать папку и сохранить», разрешение Chrome
сбрасывает). Сменить папку — ссылка «изменить» в попапе рядом с именем
текущей папки.

Copy to clipboard копирует markdown с исходными (абсолютными) ссылками
на картинки.

## Сборка из исходников

```
npm install
npm run build      # esbuild → dist/
```

Исходники: `src/content.js` (извлечение + конвертация, инжектится в страницу),
`src/popup.js` (кнопки, скачивание), `src/manifest.json` (MV3).

Технические детали: `defuddle/full` — предсобранный бандл со встроенным
Turndown, поэтому лишнее экранирование убирается пост-обработкой markdown
(функция `fixEscaping` в `content.js`), код-блоки при этом не затрагиваются.
